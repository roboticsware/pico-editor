# Android Platform Setup

## Overview
This directory contains the Android platform code for Pico Editor, generated by Capacitor. The app is optimized for Android tablets.

## Requirements
- Android Studio (latest version recommended)
- Android SDK API level 24 or higher
- Java Development Kit (JDK) 17 or higher

## Building the App

### From Project Root
```sh
# Build web assets and sync to Android
yarn android:build

# Open in Android Studio
yarn android:open

# Or build and run on connected device
yarn android:run
```

### From This Directory
After building the web app, you can also work directly in Android Studio:
1. Open this `android` folder in Android Studio
2. Wait for Gradle sync to complete
3. Connect your Android tablet (with USB debugging enabled) or start an emulator
4. Click "Run" (Shift+F10)

## USB Serial Support
The app includes USB host permissions for serial communication with Raspberry Pi Pico devices. However, note that Android's Web Serial API support is limited compared to desktop browsers.

## Tablet Optimization
The app is configured to support large and xlarge screen sizes, making it suitable for Android tablets.
